## About

Self-taught security practitioner with 1+ years of hands-on experience — built through practice, not theory.

I like understanding *how* systems break, then building tools that make that process faster and more repeatable. Most of my work lives in Python, targeting recon automation, web exploitation utilities, and network analysis tooling.

Currently building a combined offensive-security toolkit and exploring AI-assisted security tooling.
