## About

Self-taught security practitioner with 1+ years of hands-on experience — built through practice, not theory.

I like understanding *how* systems break, then building tools that make that process faster and more repeatable. Most of my work lives in Python, targeting recon automation, web exploitation utilities, and network analysis tooling.

Currently building a combined offensive-security toolkit and exploring AI-assisted security tooling.

## Experience

### Authorized School Network Security Assessment
Full security assessment of a school network, conducted with written authorization from the IT department.

**Findings**
- Default credentials on multiple network devices
- SSH and RPC services exposed across the internal network
- Minimal hardening on critical internal systems

**Outcome** — Delivered a formal findings report; all issues were remediated (credentials rotated, unnecessary services disabled).

### Bug Bounty
- Identified and reported XSS vulnerabilities across multiple targets
- Wrote proof-of-concept exploits and submitted responsible disclosures
- Hands-on experience across the full web application security workflow

### Independent Security Projects — Ravix & Alovera
Worked as both developer and security consultant on two independent projects.
- Analyzed application logic flaws, access control weaknesses, and internal workflow vulnerabilities
- Built and hardened client-side components with a focus on stability and secure design
- Delivered iterative security improvements across multiple project cycles
